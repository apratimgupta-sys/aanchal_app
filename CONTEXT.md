# RMC Anchal Office Monitoring

This context describes daily service activity reported by Anchal offices for RMC commissioner review.

## Language

**Opening balance**:
The pending service work, complaints and field tasks for one service at the start of an office's reporting-start date. It is a one-time baseline for an Anchal office.
_Avoid_: opening-balance adjustment, daily opening balance

**Reporting-start date**:
The first service date for which an office may report in this portal. Opening balances describe the position at the start of this date.
_Avoid_: setup date, reporting date

**Service date**:
The date on which a reported service activity occurred. It identifies whether an entry belongs to Today’s Entry or Backdate Entry.
_Avoid_: reporting date

**Registration date**:
The date and time at which the portal first accepted an entry. It is assigned by the server and is never backdated.
_Avoid_: submission date, reporting date

**Backdated entry**:
An entry with a service date before today and on or after its office's reporting-start date.
_Avoid_: historical entry, late entry

**Correction**:
A saved entry's replacement values, recorded with a reason while retaining the prior values in change history.
_Avoid_: overwrite, edit without history
